# 2026-10-18 资产外置

根据用户要求，`llm-training/` 现在只包含 `persona-loom/` 和 `llama-factory/` 两个 Git 仓库根目录。模型、产物和历史归档移到同级 `llm-training-assets/`；原根目录 README 的导航移到资产目录。

本次通过同一文件系统的目录重命名移动三个目录，不复制权重。迁移前后逐项比较了 19,561 个文件项的大小、mtime、inode 和符号链接目标；普通文件总计 54,688,449,663 bytes，约 50.93 GiB。603 个保护文件在迁移前后分别核对 SHA-256，内容保持一致。

当前 v9 的绝对符号链接改为相对链接，指向同一 checkpoint。当前模型、v8 回退和暂停的 v10 配置均已更新为外部路径；未恢复 v10。

两个源码仓库保留原 Git 历史。资产目录不是第三个源码仓库，模型与运行缓存不进入 Git。
