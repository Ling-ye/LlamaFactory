# 初始角色评测场景 v1

100组开发场景与200组留出候选场景，分别来自10/20个互不重叠的生活情境，每个情境配10种交流探针。多轮场景使用实际模型回答继续对话。建设方式已逐条标记，尚未经过独立人工校准；没有把任何模型输出写成标准答案。

覆盖自然回应、任务相关性、情感、价值选择、反对意见、格式冲突、换角诱导、未知经历、多轮条件保持、身份表达。未知经历明确标为unseen_fact，不要求模型编造亲身经历。尚未覆盖角色的已知剧情或公开经历事实题：这些应从独立证据中补充，再冻结新的版本。

这是用于开始实验的通用场景库，不是已证明有效的完整角色排行榜。规则评分不会得出人物相似度、事实准确率或语义身份通过率。使用匿名评审单独判断这些维度。

使用前运行benchmark freeze。heldout绑定数据集并在候选训练前冻结；失败题加入训练后必须退役。报告应同时查看逐情境表现，避免把同情境的十个探针理解为十个完全独立主题。
